01 / EDGE HARDWARE

Raspberry Pi and Android TV sensors on a real home network

A Raspberry Pi measures both Wired Ethernet and Wi-Fi at the same time: HTTP and ICMP path checks, LibreSpeed throughput tests, Kismet wireless intrusion detection, on-demand LAN scans, and a custom Rust real-time UDP stream generator (Voice G.711 A-law/µ-law and Video). An NVIDIA Shield Android TV agent adds QR-onboarded Wi-Fi voice and throughput telemetry from the living room.

Architectural trade-off Heavy tests run spaced in a serialized queue, not as parallel streams that would peg the Pi's CPU, saturate the residential uplink, and create the very lag being measured.

02 / SECURITY AND NETWORKING

Access plane and measurement tunnels, kept apart

Devices enroll with Ed25519 signatures and pin the server's TLS certificate. Wired (wg0) and Wi-Fi (wg1) each maintain an isolated WireGuard tunnel. When an ISP blip leaves a stale route pin, the agent detects that public web works while the tunnel peer is unreachable and self-heals within 60 seconds.

Why it matters Separating public web checks from WireGuard tunnel checks prevents false "Wi-Fi Down" alarms when only a measurement tunnel dropped. HSTS, a strict CSP, and server-side RBAC protect the public guest demo.

03 / PORTABLE CLOUD STACK

FastAPI, PostgreSQL and hierarchical correlation

Deployed with plain Docker Compose and Caddy on Oracle Cloud, with no proprietary lock-in. The alert engine evaluates a strict hierarchy (Pi offline → shared WAN outage → upstream bandwidth collapse → single link → tunnel) and suppresses downstream alert noise automatically, while Server Health monitors disk forecasts, encrypted off-host backups, and weekly CVEs.

Architectural trade-off Gave up familiar AWS and GCP managed services to prove the entire stack can move to any Linux host or bare metal without rewriting code.

04 / HOW IT WAS BUILT

Coding agents, working inside written knowledge

The platform was not one open prompt. Architecture, security, and delivery rules were written first in SPEC.md and CLAUDE.md: remote agents push, browsers only read, roles are enforced on the server, secrets never enter a public repo, and an alert names the cause rather than every symptom under it. Several coding agents then implemented on isolated branches. Each change went through pull-request review, server tests in a throwaway database, and a TypeScript build before it reached the live system.

Kismet WIDS on a radio that listens and never joins a network: nearby Wi-Fi, clients, and wireless security.

Ed25519 device enrollment, pinned TLS, and dual self-healing WireGuard tunnels that keep measurement and access on separate planes.

REAL-TIME HEALTH

Synthetic voice and video

A custom Rust UDP generator sends G.711 voice and video streams over the link, queued so the test does not create the lag it reports.

SERVER HEALTH

Capacity forecast and backups

Disk forecast, encrypted backups, and the host the platform runs on, separate from the home network.

SECURITY

The platform is public, so the server behind it is managed like production: owned end to end, kept patched, and locked down in layers, from the sensor to the dashboard.

IN TRANSIT

Encrypted end to end

HTTPS with automatically renewed certificates, HSTS and a strict CSP, WireGuard tunnels to every sensor, and a pinned TLS key for enrollment.

IDENTITY

Every sensor proves who it is

Devices enroll with their own Ed25519 key and signed requests, and nothing joins until an admin approves it.

ACCESS

Read-only for guests

Visitors see live graphs through a guest role enforced on the server. Private details are removed in the API itself, not just hidden on screen.

PATCHING

Vulnerability tracking

Server Health checks the installed software against known CVEs every week, so unpatched packages are seen and fixed.

RECOVERY

Encrypted off-host backups

Backups are encrypted and kept off the host, and a disk forecast warns before the server runs out of room.

CHANGE CONTROL

Nothing ships unchecked

Every change passes tests and review before it reaches production, and the rules say what must stay private.

WHAT THE RULES REFUSED

No always-on language model reading logs. Deterministic correlation runs first.

Gemini is on demand, for a root-cause note or a fault walkthrough, and a guest session is read-only with the home address removed on the server.
